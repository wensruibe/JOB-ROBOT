# 金句卡片生成器 PRD

## 1. 产品概述
- 目标：提供一个网页工具，用户输入金句后，生成高颜值的金句卡片图片，可预览、导出与下载。
- 场景：社媒分享、文章配图、演示封面、朋友圈/群聊传播。
- 设计参考：柔和渐变背景 + 圆角卡片 + 左侧头像 + 昵称标题 + 金句正文 + 左下时间与日期 + 右上角小徽标。

## 2. 用户故事
- 作为创作者，我希望输入金句并一键生成图片用于社媒分享。
- 作为运营人员，我希望可批量快速生成统一视觉风格的金句卡片。
- 作为普通用户，我希望自定义背景与样式后下载高清图片。

## 3. 关键页面与模块
- 编辑器页（单页应用）
  - 左侧：可实时预览的画布（Canvas/SVG/HTML渲染）。
  - 右侧：表单配置面板（文案、作者、时间、样式、导出）。
  - 顶部：返回/重置/帮助入口；底部：生成与下载按钮。

## 4. 界面元素与视觉规范
- 背景
  - 默认：柔和多色渐变（示例：桃粉→淡紫→浅蓝），支持模糊光晕。
  - 预设：4–8组渐变主题；支持自定义两端颜色与角度。
  - 可选：纯色背景、上传背景图（自动高斯模糊与亮度压暗）。
- 卡片
  - 形态：浅色半透明/纯白卡片，超大圆角，外投影柔和。
  - 阴影：多层低不透明度阴影，避免生硬边缘。
  - 内边距：大间距排版，留白充足。
- 头像与昵称
  - 头像：左上圆形头像，支持上传/选择默认占位图；尺寸可调。
  - 昵称：头像右侧加粗标题文本，字重偏粗，颜色接近纯黑但稍柔和。
  - 文本不可超出卡片；超出时自动省略或换行。
- 金句正文
  - 字体倾向：中文衬线或优雅无衬线；默认使用系统可用字体组合。
  - 行距与段落：大行距，禁用孤行；支持自动换行与软回车。
  - 对齐：左对齐；支持用户切换居中/两端对齐。
- 时间与日期
  - 位置：卡片左下角的次要信息行。
  - 格式默认：HH:mm · DD MMM, YYYY（可选择中文本地化示例：16:14 · 2025年9月18日）。
- 右上角徽标
  - 小尺寸圆角方形图标，可自定义/上传，支持隐藏。

## 5. 输入项与配置
- 文案
  - 金句文本（必填）：支持多行与标点；粘贴后自动去除前后空格。
  - 作者/昵称（选填）：显示在标题位置；为空则隐藏头像与昵称区块或仅显示占位。
- 媒体
  - 头像上传：jpg/png/webp，自动裁剪为圆形，最大 2MB。
  - 徽标上传：方形建议 128×128；支持尺寸与圆角调整。
- 背景
  - 预设主题选择 + 自定义渐变（两端色、角度、强度、模糊）。
  - 模糊强度滑杆（0–40px）。
- 卡片样式
  - 圆角（12–40px）、阴影强度、卡片透明度。
  - 卡片宽度比例（相对画布 70–92%）。
- 排版
  - 正文字体大小、行距、字重、对齐方式。
  - 标题（昵称）字体大小与字重。
- 元信息
  - 时间日期：自动取系统时间；可改为自定义。
  - 语言/本地化：中文/英文日期格式切换。
- 导出
  - 分辨率：1x/2x/3x（默认 2x 高清）。
  - 画布尺寸预设：1080×1350（竖）、1200×900（横，默认）、1280×720、1024×1024。
  - 格式：PNG（默认无损）、JPG（质量可调）、WEBP。
  - 文件名规则：quote-YYYYMMDD-HHmm.png（可自定义）。

## 6. 交互流程
1) 打开工具 → 载入默认背景与卡片。
2) 输入金句 → 实时预览排版变化。
3) 上传头像（可选）与填写昵称（可选）。
4) 调整背景、卡片与排版参数 → 预览即时更新。
5) 设置时间日期与徽标（可隐藏）。
6) 点击“生成/下载” → 输出选定格式与分辨率图片。

## 7. 生成与排版规则
- 文本换行：基于容器宽度的智能换行，确保词/字完整性；英文采用单词断行，中文按字符。
- 段落安全边距：卡片四边至少 24–36px 内边距。
- 溢出处理：超长文本提供三策略——自动缩小字号、启用滚动截断提示、提示用户剪短文本。
- 对比度校验：文本颜色与卡片背景对比度至少达到 WCAG AA。
- 头像与昵称联动：无昵称时头像可隐藏；仅昵称时显示默认头像占位或允许关闭头像。
- 日期本地化：跟随用户语言或显式选择；国际化库或自实现。

## 8. 非功能需求
- 性能：预览参数变更 < 50ms 响应；导出在常见设备 < 1s（1080p）。
- 兼容性：现代桌面浏览器（Chrome, Edge, Firefox, Safari 最新两个版本）；移动端适配基础操作。
- 隐私：头像与徽标仅在本地处理；不默认上传服务器（前端纯生成）。
- 无障碍：控件可键盘操作；为关键按钮与图像加可访问名称。

## 9. 技术实现建议
- 渲染：优先使用 HTML+CSS+SVG 组合渲染，导出用 Canvas 转绘（例如：DOM → Canvas）。
- 背景效果：CSS 渐变 + 模糊滤镜；导出时在 Canvas 端复现。
- 字体：系统字体优先，中文推荐组合：PingFang SC / Microsoft YaHei / Source Han Sans / Noto Serif SC（按可用性降级）。
- 本地化：原生 Intl.DateTimeFormat 或轻量日期库。
- 状态管理：单页本地状态即可（URL 参数分享可选）。

## 10. 测试用例（示例）
- 输入 1 行/多行中文金句，预览与导出无断字。
- 切换 4 组预设渐变，阴影与圆角正常变化。
- 头像上传非正方形时自动裁剪为圆形；超 2MB 提示。
- 隐藏徽标后，右上角留白不坍塌。
- 日期切换到中文格式并保持与系统时区一致。
- 导出 PNG 2x，尺寸与清晰度符合期望。

## 11. 埋点（可选）

- 渐变主题使用频次、头像上传率。
